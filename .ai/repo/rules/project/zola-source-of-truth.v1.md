# Rationale

The site is a publishing system: the next artifact must be a Markdown file pair, not a template edit.

# Required behaviour

- Never hand-write or commit generated HTML (`public/`, `.preview/`).
- Never duplicate templates per locale or branch on `lang` in templates; use `trans(key=…, lang=lang)`
  and per-locale content files (`index.md`, `index.cs.md`).
- Every public content file exists in every locale with the same front-matter shape
  (`scripts/validate-i18n.py` enforces it).
- Asset and page URLs come from `get_url`, `resize_image` or Zola permalinks, so they include the
  repository subpath; never hard-code `/assets/…`.
- Content stays readable without JavaScript. Alpine and Flowbite enhance; they never own content.
- One owner per piece of DOM state: Alpine or Flowbite, never both.

# Failure behaviour

`scripts/validate.sh` fails the build on missing translations, undefined UI strings, broken references and
anchors. Violations it cannot see (template branching on language, duplicated state ownership) are review findings.

# Verification

`npm run validate` and `npm test`; reviewer for the rest.
