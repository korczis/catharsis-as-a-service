These articles describe how Catharsis as a Service™ was made: the architecture of a bilingual static publication, the way one person directed an AI coding agent (Claude Code) under the supervision of [Majordomus](https://majordomus.dev), the data model that keeps every public claim dated and graded, the tests that stand between a commit and a release, and what the records say about time.

They follow the same rule as the research notes: numbers come from records (the Git history, the GitHub Actions runs, the release list and the Majordomus ledger), each is linked to its source, and estimates are labelled as estimates. The [case study](../case-study/) presents the same records as an interactive timeline; these articles explain the engineering behind them.
